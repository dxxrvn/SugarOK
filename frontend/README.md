# СахарОК

Дневник самоконтроля для людей с сахарным диабетом: записи глюкозы, график за неделю, дневник, лекарства, визиты к врачу и отчёт для врача.

**Стек:** React, Vite, React Router. Бэкенд: Node.js, Express, SQLite (папка `backend`).

## Запуск

Сначала запустите бэкенд (см. `backend/README.md`), он работает на `http://localhost:3000`.

```
npm install
npm run dev
```

Приложение откроется на `http://localhost:5173`.

## Структура

- `src/api.js` — все запросы к серверу и обновление токенов
- `src/auth.jsx` — состояние входа (кто сейчас в аккаунте)
- `src/components` — шапка, меню, защита страниц от неавторизованных
- `src/pages` — страницы приложения
- `src/utils.js` — небольшие функции для дат и текста

## Как хранится вход

Access-токен живёт только в памяти страницы. Refresh-токен хранится в httpOnly cookie и недоступен для JavaScript. После перезагрузки страницы приложение само получает новый access-токен по этой cookie.
