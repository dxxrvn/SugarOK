# SugarOK backend

## Это краткий readme по запуску backend конфигурации.

Привет! Это бэкенд проекта SugarOK - сайта для диабетиков.
**Стек:** Node.js, Express, SQLite (better-sqlite3)
**Эндпоинты:**

| Метод  | Путь                                   | Описание               |
| ------ | -------------------------------------- | ---------------------- |
| POST   | /api/measurements                      | Создать измерение      |
| GET    | /api/measurements                      | Все измерения          |
| GET    | /api/measurements/latest               | Последнее измерение    |
| GET    | /api/measurements?from={date}to={date} | Измерения в промежутке |
| GET    | /api/measurements/:id                  | Одно измерение         |
| PUT    | /api/measurements/:id                  | Полная замена          |
| PATCH  | /api/measurements/:id                  | Частичное обновление   |
| DELETE | /api/measurements/:id                  | Удалить                |

## 1. Установка node.js

Можно установить как через bash, так и через браузер.
Покажу вариант с браузером:

1. Заходите на страничку **https://nodejs.org/en/download**
2. Выбираете в колонках по иерархии: **версию, операционную систему, менеджер версий (советую брать nvm), менеджер пакетов (советую брать npm).**
3. Листаете вниз, нажимаете на зелёную кнопку установки.
4. Устанавливаете node.js на ПК.
5. В powershell (Windows) или bash (Linux) проверяете, все ли установилось, с помощью команд:

<pre>
# Powershell/bash
node -v
</pre>

При успешной установке в консоль придёт ответ: v{actualVersion}. Например: v24.21.0

## 2. Копирование репозитория с GitHub себе на ПК

Покажу вариант с графическим интерфейсом VSCode (все можно сделать через powershell/bash) - необходимо установить его на ваш компьютер, его установка в инструкции показана **не будет**.

1. В левой нижней части экрана заходите в аккаунт GitHub через удобный для вас способ.
2. Во вкладке Source Control (**Ctrl + Shift + G**) в левой части экрана выбираете "**Clone repository**", вставляете ссылку на этот репозиторий.
3. Готово.

## 3. Установка необходимых зависимостей

<pre>
# Powershell/bash
cd backend 
# попадаем в нужную папку
npm install
</pre>

## 4. Запуск сервера

Тут в целом всё просто, запуск происходит одной командой:

<pre>
# Powershell/bash
node main.js
</pre>

Главное убедитесь, что запускаете команду из папки SugarOK/backend.

**На этом пока всё!**
